## 2. Confirmed findings

Severity labels are the six outcome classes specified for this audit. Class 1 is the highest priority: a wrong value reported as measured.

### Class 1: wrong values reported confidently

#### F1. Blank and NaN EVOLVEpro scores become competitive measured zeros

Location: kuma_core/kuro/evolvepro.py:425-475 and 695-706.

Executed input: descending-score CSV containing A2V=-1.0 and A3V with a blank score, top_n=1. A separate run used valid scores -1 and -2 plus NaN.

Actual: the blank/NaN row became 0.0 and was selected ahead of valid negative predictions; the first run returned variants=["A3V"], y_preds=[0.0].

Correct: blank and NaN predictions are unknown and must be rejected or explicitly excluded, never ranked as measured zero.

#### F2. Duplicate variant rows consume selection capacity and overwrite the reported score

Location: kuma_core/kuro/evolvepro.py:588-599 and 691-706.

Executed input: A2V=10, A3V=9, A2V=1 with top_n=3.

Actual: variants=["A2V","A3V","A2V"], y_preds=[1.0,9.0,1.0], selected_count=3. The best A2V score 10 was replaced by the last row’s 1.0.

Correct: one biological variant must occupy one slot, with an explicit duplicate-resolution policy or a refusal on contradictory scores.

#### F4. Residue position zero edits DNA upstream of the CDS

Location: kuma_core/kuro/mutation.py:13 and 103-128.

Executed input: mutation A0G, sequence GCTATG, target_start=3.

Actual: position=0, codon_start=0, before GCTATG, after GGCATG. A syntactically accepted “0th residue” changed the upstream GCT codon.

Correct: amino-acid positions are 1-based; A0G must be rejected.

#### F5. Colon-delimited start-codon substitutions bypass the biological exclusion

Location: kuma_core/kuro/evolvepro.py:478-485 and 579-585.

Executed input: scored rows M1A:A2V=2 and A3V=1.

Actual: both were selected and start_codon_removed=0.

Correct: any component at position 1 must exclude the whole variant, independent of supported combo delimiter.

#### F6. Negative scores erase entropy and change diversity selection by arbitrary score origin

Location: kuma_core/kuro/evolvepro.py:238-260.

Executed input: position-score groups {-1,-1} and {-1,-3}; then the identical ordering shifted by +4.

Actual: negative input produced entropy {10:0.0,20:0.0}; shifted input produced {10:1.0,20:0.8113}.

Correct: entropy/diversity must be invariant to an additive score offset, or the accepted score domain must be enforced.

#### F7. Malformed compound mutations are partially accepted after silently deleting tokens

Location: kuma_core/kuro/mutation.py:49-80 and 132-174.

Executed input: CSV rows A0G/BAD and BAD.

Actual: split returned ["A0G"] and []; parse_mutations returned only A0G. The invalid half and entire invalid row disappeared.

Correct: a malformed non-WT token must reject or explicitly fail the complete source row; it must not silently change the intended genotype.

#### F8. Primer overlap generation assumes a circular junction without receiving topology

Locations: kuma_core/kuro/overlap.py:18-60 and kuma_core/kuro/sdm_engine.py:887.

Executed linear input: sequence ABCDEFGHIJ, codon_start=2, overlap_len=8.

Actual: one window EFGHIJAB, inventing a 3′→5′ junction. Correct linear result: no window.

Executed circular control: the real Q232A fixture produced one candidate at its original origin but zero after rotating the same circular molecule so codon_start=2.

Correct: linear inputs must not wrap; circular designs must be invariant to rotation of the sequence origin.

#### F9. Reverse-strand and compound CDS metadata point design at the wrong bases/length

Location: kuma_core/kuro/sdm_engine.py:1688-1814 and 1908-1913.

Executed reverse-strand feature: genomic bases at reported cds_start were TTA, strand-aware extraction began ATG, reported cds_start=0, translation=MPG.

Actual: the UI-visible start points to TTA and later deterministically fails the ATG design gate.

Executed compound feature: genomic span 18 nt, extracted CDS 12 nt, translation MKF.

Actual: aa_length=6; under the existing Python convention, the correct aa_length is 4.

Correct: returned coordinates must represent an oriented, designable CDS; the 12-nt compound CDS must report aa_length=4, derived from the extracted location rather than its bounding interval.

#### F10. Q5 SDM’s declared full-overlap default is ignored

Locations: kuma_core/kuro/polymerase.py:49-103, kuma_core/kuro/resources/polymerase_profiles.json:338, kuma_core/kuro/sdm_engine.py:995 and 1876.

Executed real fixture with Q5 SDM and omitted overlap mode versus explicit full.

Actual: omitted mode produced 5 partial results and 7 failures; explicit full produced 11 full results and 1 failure.

Correct: omission must resolve to the selected profile’s default_overlap_mode=full.

#### F11. Duplicate residue positions change dispersion’s scientific classification

Location: kuma_core/kuro/dispersion.py:220-285.

Executed on a 30-residue linear coordinate set with the same fixed seed.

Actual: positions [1,1,2] gave mean 0.6667, percentile 0.0, class clustered; [1,2] gave mean 1.0, percentile about 7, class random.

Correct: repeated reporting of one residue must not add a zero-distance biological observation or change the null model/classification.

#### F12. A position with no Cα is omitted from the calculation but still reported as mapped

Location: kuma_core/kuro/dispersion.py:211-216 and 220-285.

Executed input: mapped positions [1,2,3] with coordinate 2 absent.

Actual: mapped=[1,2,3], dropped=[], n_positions=2.

Correct: position 2 must appear as dropped/uncomputed; the response must not claim it was structurally mapped while excluding it from the number.

#### F13. “Top 10%” floors the number of hits

Location: kuma_core/kuro/benchmark.py:171-172.

Executed input: 19 ground-truth variants, selecting rank 2, top_percentile=10.

Actual: threshold was rank 1 and hit_rate=0%. Only 1/19 (5.26%) qualified.

Correct: a top-10% set over 19 items contains two items under the usual ceiling definition, or the alternative policy must be named rather than reported as 10%.

#### F14. Missing Cα data is represented as maximum structural diversity

Location: kuma_core/kuro/alphafold.py:213-242.

Executed distance input with one missing coordinate.

Actual: ca_distance returned 1.0, the maximum normalized distance.

Correct: missing evidence must be unknown/excluded; it must not receive the strongest diversity score.

#### F15. Non-finite structure coordinates/confidence propagate as measurements

Locations: kuma_core/kuro/structure_file.py:73-145 and kuma_core/kuro/alphafold.py:91-121.

Executed mmCIF and PDB records containing NaN.

Actual: parsed coordinate arrays contained nan, mean confidence became nan, and pairwise distance returned nan.

Correct: non-finite structural values must be rejected or represented as missing before ranking or distance calculations.

#### F16. Multiple PDB models are merged into a fabricated interface

Location: kuma_core/kuro/interface.py:40-118.

Executed PDB: model 1 placed chain A at 0 Å and B at 100 Å; model 2 reversed them. Each model individually had no interface.

Actual: the combined parser reported interface residue {1}.

Correct: choose one model or calculate models separately; atoms from different experimental models must never contact each other.

#### F17. Cα normalization is nondeterministic for the same structure

Location: kuma_core/kuro/alphafold.py:245-277.

Executed the same 1,000-residue coordinate list repeatedly.

Actual: ca_max_dist varied across calls (observed series 985, 995, 994, 995, 999, 992 Å; an independent rerun likewise varied).

Correct: the same coordinates must yield the same normalization and therefore the same selection distances.

#### F18. Accepted terminal sequence offsets are not applied to structure coordinates

Location: kuma_core/kuro/interface.py:247-269 and downstream direct indexing.

Executed input: structure sequence XXABC against reference ABC, with coordinates whose direct positions 1–2 and correctly offset positions 3–4 differ.

Actual: structure_matches_reference returned true; direct normalized distance was 0.0333 while offset-correct distance was 0.6667.

Correct: accepting the sequence frame requires returning/applying its offset, or the structure must be rejected.

#### F26. Echo reverse source plate follows the destination plate instead of the reverse mapping

Location: kuma_core/kuro/plate_mapper.py:917-929.

Executed input: M1 forward on plate 1, M97 forward on plate 2, one shared reverse mapping on plate 1.

Actual M97 reverse row aspirated Source [2]/B1 and dispensed Destination [2]/A1.

Correct: aspirate Source [1]/B1, where the shared primer actually exists, or explicitly create a plate-2 source mapping.

### Class 2: silent drop, duplication, or overwrite

Actual: rglob_paths returned {"*.fastq": []}.

#### F35. Scientific plate-list columns are discarded

Location: kuma_core/kuro/plate_mapper.py:143-199 and 535 onward.

Executed SdmPrimerResult with primer Tm 61.2, overlap Tm 42.1, WT codon GCT, mutant codon GGT.

Actual: the Excel Fwd List cells for Tm, overlap Tm, WT codon, and mutant codon were [None,None,None,None]. The real design CLI reproduced the loss for 10 primers.

Correct: the workbook must preserve and report the design values supplied by the upstream result, or omit those columns rather than silently discard them.
