# 라이선스 근거 수집과 배포 검토

## 프로젝트 라이선스

루트 [LICENSE](../../LICENSE)와 README가 표시하는 KUMA 라이선스는 MIT가
아니라 GNU GPL version 2다. 서드파티의 MIT 고지는 프로젝트 라이선스를 바꾸지
않는다. 이번 정리는 KUMA를 재라이선스하거나 GPL-2.0-only와
GPL-2.0-or-later 중 하나를 새로 선택하는 작업이 아니다. 기여자나 고용기관을
대신해 권리를 부여하지 않는다. 정확한 허락 범위와 대체 라이선스를 발급할 권한은
권리자가 확인해야 한다. GPL 본문 끝의 적용 예시만 보고 프로젝트에 "or later"
권한이 있다고 추정하지 않는다.

## 자동 수집 범위

| 출처 | 수집하는 근거 | 범위의 한계 |
|---|---|---|
| pnpm production 목록 | 실제 설치된 이름·버전, 라이선스 표시와 LICENSE/LICENCE/COPYING/NOTICE/COPYRIGHT 본문 및 해시 | 식별자만 보고 이용 허락을 만들어 내지 않음 |
| Python 프로젝트 의존성 | 설치된 Requires-Dist의 전이 의존성, 플랫폼 조건, 요청된 extra, wheel licenses 디렉터리 등의 법적 고지 | 개발 환경의 모든 패키지를 무조건 포함하지 않음 |
| Python build extra | PyInstaller를 포함한 패키징 의존성을 별도 역할로 표시 | 도구 전체가 런타임에 배포되는 것은 아니며 부트로더 조건은 별도 |
| Cargo | 기존 cargo-about 결과와 선택된 라이선스 본문 | 허용 SPDX 목록은 라이선스 조합의 호환성 승인과 다름 |
| 번들 바이너리 | NOTICE-bundled.md | 인터프리터·네이티브 도구·연결 라이브러리는 실제 배포본 확인 필요 |

Node와 Python 수집기는 Markdown과 JSON 목록을 생성하고 실제 설치 버전과
고지 본문의 SHA256을 기록한다. 이것은 근거 목록이지 SPDX SBOM이나 상용화
승인서가 아니다. Python 수집의 출발점은 certifi를 포함한 pyproject.toml의
선언이다. 의존성을 바꿀 때 별도의 패키지 이름 목록을 수정할 필요가 없다.
플랫폼 조건은 각 배포 운영체제에서 평가한다. test·benchmark extra는 배포
수집의 출발점에 넣지 않는다.

필수 패키지 누락, 버전 불일치, 빈 목록, 고지 본문 누락은 수집 실패로 처리한다.
실패를 없애려고 패키지를 제외하거나 일반 MIT/GPL 양식으로 본문을 대체하지
않는다. 해당 배포 아티팩트의 원문과 저작권자를 보존해야 한다. 상위 패키지
자체의 고지가 불완전할 수도 있으므로 수집 성공이 법적 완전성 증명은 아니다.

최종 NOTICE는 변경하지 않은 프로젝트 LICENSE, Rust·Node·Python 수집 결과,
별도로 관리하는 바이너리 고지를 합쳐 src-tauri/resources/NOTICE.md에 넣는다.
누락·빈 내용·placeholder 입력은 병합을 중단한다. License evidence CI가
생성물을 검토용으로 보관하며, 실제 릴리스에서는 다른 플랫폼 결과를 재사용하지
않고 해당 빌드 환경에서 다시 수집한다.

## 자동으로 승인할 수 없는 배포 사항

상용 배포 전에 아래 각 적용 항목의 검토자, 배포본 해시, 근거와 결론을 기록한다.
검토가 기록되기 전에는 **미해결 사항**이다. 체크리스트를 추가한 것으로 권리
확인이나 상용 배포가 승인되는 것은 아니다.

- **라이선스 선언과 권리 귀속:** GPL 버전 범위, 기여자 권리, 기관·고용주 허가를
  확인한다. 권한 확인 없이 루트 라이선스를 바꾸거나 비공개 라이선스를 약속하지
  않는다.
- **호환성과 대응 소스:** 실제 의존성 버전, 대체 라이선스 선택, 연결·번들 경계와
  소스 제공 방식을 검토한다. cargo-about 허용 목록에 Apache-2.0이 있다는
  사실만으로 GPLv2-only 결합물과의 호환성을 입증할 수 없다. GPL 라이브러리와
  MPL 적용 파일 등의 의무도 따로 확인한다. NOTICE는 대응 소스가 아니다.
  배포 버전에 대응하는 원본·수정사항·빌드 및 설치 자료를 보관한다.
- **네이티브 코드와 패키징:** 플랫폼별 최종 실행파일, Python 인터프리터,
  연결·런타임 라이브러리와 PyInstaller 부트로더를 확인한다. 정적 링크만으로
  고지·소스 의무가 없어지는 것은 아니다. Windows의 MinGW/GCC/runtime
  패키지 버전과 해당 고지 본문을 보관한다.
- **자산·예제·데이터:** 배포 이미지, 아이콘, 폰트, 샘플 데이터, 논문 표와 문서의
  출처·저자·라이선스·변경 내용·허락 근거를 기록한다. 인용은 이용 허락이 아니다.
  외부 발표자료가 앱에 들어 있다고 추정하거나 코드 라이선스가 외부 자산에도
  적용된다고 가정하지 않는다. NC·ND·권리 미확인 자료는 해당 상용 용도에 대한
  별도 허락을 받거나 배포에서 제외한다. 비공개 실험 데이터를 근거로 공개하지
  않는다.
- **모델과 외부 서비스:** 사용자 예측 CSV를 읽는 기능과 모델 코드·가중치를
  재배포하거나 서열을 외부로 전송하는 기능을 구분한다. 제공자 약관, 데이터
  이용 제한과 고객 동의를 기록한다. 코드 라이선스만으로 해결되는 항목이 아니다.

자사 서버 실행, 브라우저 JavaScript 전달, 설치본 판매, 고객용 컨테이너 전달은
서로 다른 경계다. 실제 전달 모델로 검토하며 SaaS나 별도 프로세스라는 이름만으로
모든 의무가 면제된다고 보지 않는다. 이 문서는 기술적 검토 절차이지 법률 의견서가
아니다.
