# Step 3. Janus 장비 설정

선정된 클론을 로봇이 집을 수 있는 형태로 바꾸는 단계다. 선택 단계이며 어떤 실행도 막지 않는다. 시퀀싱 판정만 필요하면 step 2 에서 멈추면 된다.

v0.15.12 에서 step 2.1 밖으로 분리됐고 v0.15.14 에서 팝업이 사라졌다.

## 실행이 쓰는 파일과 여기서 쓰는 파일

| 파일 | 누가 쓰나 | 내용 |
|---|---|---|
| `..._picks.csv` | step 2 의 실행이 자동으로 | 선정 클론 목록 (`legacy5`) |
| `..._janus.csv` | step 3 에서 내보내기를 눌렀을 때만 | 로봇이 읽는 9열 시트 (`device9`) |

분석은 pick 목록까지만 만든다. 로봇 시트는 deck 배치와 liquid class 를 함께 적는 파일이고 이 값들은 내보내는 시점의 실험실 상태를 진술한다. 재실행할 때마다 자동으로 다시 쓰면 그때 적힌 값이 지금도 맞다고 주장하는 셈이라, 사람이 누를 때만 만든다.

## 화면 구성

step 3 은 전용 화면이므로 설정이 페이지에 그대로 펼쳐진다. v0.15.13 까지는 "Janus 장비 설정 열기" 버튼이 다이얼로그를 띄웠다. 미리보기를 모달 안에서 읽어야 했고 화면이 남는데도 좁았다.

- **형식**: CSV 또는 XLSX
- **대상 배치**, **출력 열 구성**: 목적지 플레이트 배치와 내보낼 열 구성
- **장비 설정**: Volume (µL), Liquid class
- **Deck 구성**: sample type, 소스 rack 번호(플레이트별), 목적지 rack 번호
- **미리보기**: 실제로 나갈 행을 보여준다. 차단·경고 항목이 있으면 함께 표시한다
- **제외 N건**: 선정에서 빠진 클론과 그 이유
- **내보내기**

## 값을 비워 두면

**Liquid class 는 기본값이 없다.** 로봇의 피펫팅 거동을 결정하는 값이라 프로그램이 대신 정하지 않는다. 비워 두면 그 칸이 빈 채로 나가고 내보내기는 진행된다. 실행 전에 내보내기 화면이나 시트에서 채운다.

**Deck 번호는 이번 실행의 플레이트에서 유도한다.** 소스 플레이트가 플레이트 순서대로 앞쪽 rack 을 받고 목적지가 그다음을 받는다. KURO 프라이머 시트와 같은 규칙이다. 내보내기 화면에서 숫자를 입력하면 각각 덮어쓸 수 있다.
