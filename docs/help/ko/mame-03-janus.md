# 단계 3. Janus 장비 설정

선정된 클론을 로봇이 읽는 시트로 바꾸는 화면이다. 선택 단계이며 어떤 실행도 막지 않는다. 시퀀싱 판정만 필요하면 2단계에서 4단계로 바로 넘어가면 된다.

설정은 다이얼로그가 아니라 이 페이지에 그대로 펼쳐져 있다.

## 두 파일

| 파일 | 언제 만들어지나 | 내용 |
|---|---|---|
| `..._picks.csv` | 2단계 분석이 끝날 때 자동으로 | 선정된 클론 목록 |
| `..._janus.csv` | 이 화면에서 내보내기를 눌렀을 때만 | 로봇이 읽는 8열 시트 |

화면 위쪽 안내가 두 파일이 어떻게 되었는지 알려준다. 선정 결과 파일은 실행마다 기록된다. 장비용 매핑은 사람이 내보낼 때만 기록된다.

## 순서

1. **대상 배치** 를 고른다. `Source 위치` 는 목적지 well 을 source plate 위치 그대로 둔다. `플레이트 맵 순서로 A1부터` 는 A1, B1, C1 순으로 H1 까지 내려간 다음 A2 로 넘어가며 빈 well 을 남기지 않는다.
2. **장비 설정** 에 Volume (µL), Liquid class, type 열 값을 넣는다.
3. **미리보기** 에서 실제로 나갈 행과 생성된 plate 이름을 확인한다.
4. **제외 N건** 을 읽고 빠진 클론과 이유를 확인한다.
5. **출력 파일 경로** 를 고른다. 확장자는 `.csv` 고정이다.
6. **Janus 매핑 내보내기** 를 누른다.

시트의 8열은 `name`, `type`, `no`, `Asp. Rack`, `Asp. Posi`, `Dsp. Rack`, `Dsp. Posi`, `volume` 이다.

## 미리보기가 내는 세 가지 말

| 화면에 나오는 말 | 뜻 |
|---|---|
| 아래 문제를 해결한 뒤 내보내기가 가능합니다. | 내보내기 버튼이 잠긴다. 나열된 문제를 고친다 |
| 아래 내용대로 기록됩니다. 내보내기를 막지는 않습니다. | 프로그램이 스스로 정한 값의 목록이다. 읽고 넘어간다 |
| 미리보기를 불러오지 못했습니다 | **미리보기 다시 시도** 를 누른다. 내보내기는 계속 가능하다 |

`Source 위치` 를 골랐을 때 두 pick 이 같은 well 에 겹치면 내보내기가 실패한다.

## 제외되는 클론

PASS 클론만 시트에 담긴다. AMBIGUOUS 는 부수 indel 이 있고 LOWDEPTH 는 미검증이라 제외 목록에 표시된다. 제외 사유는 다섯 가지로 묶여 나온다.

| 사유 | 뜻 |
|---|---|
| 실패 | 판정이 실패다 |
| 선택된 plate 없음 | 해당 plate 가 이번 선택에 없다 |
| verdict 레코드 없음 | 그 well 의 판정 기록이 없다 |
| 포함하지 않은 verdict class | PASS 가 아닌 판정이다 |
| Fallback pick | 대체 후보로 잡힌 pick 이다 |

## Liquid class 와 plate 이름

Liquid class 는 로봇의 피펫팅 거동을 결정하므로 기본값을 두지 않는다. 장비 시트에는 해당 열이 없어 파일에는 쓰이지 않고 실행 기록으로만 남는다. 비워 두어도 내보내기는 진행된다.

`Asp. Rack` 과 `Dsp. Rack` 에는 deck 번호가 아니라 이번 실행의 plate 에서 생성한 plate 이름이 들어간다. 소스는 plate 순서대로 `Stock plate1`, `Stock plate2` 를 받고 목적지는 `final culture plate` 하나다. 미리보기에서 확인한 뒤 deck 라벨을 같게 맞춘다.

## 완료 표시

Liquid class 를 넣거나 매핑을 한 번 내보내면 3단계가 완료로 표시된다. 내보내기가 성공하면 저장된 경로가 화면에 남는다.
