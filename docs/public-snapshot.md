# 공개 소스 스냅샷

현재 소스 버전은 **0.16.73**입니다. `kuma` 공개 저장소는 실험 자료를 제외한 스냅샷에서 독립 Git 이력으로 시작합니다. 기존 `kuma-private`는 보존하며 과거 비공개 릴리스와 PR은 새 저장소로 이관하지 않습니다. 문서의 과거 버전·PR·CI 참조는 이전 개발 이력이며 새 공개 저장소의 검증 증거가 아닙니다.

공개 배포에는 새 업데이트 서명 키를 사용합니다. 이전 설치본에서 전환할 때는 **새 키로 서명한 첫 전환 빌드를 수동 설치**해야 합니다.

실데이터가 담긴 `docs/screenshots-mame/`와 `docs/screenshots-real/` 화면은 제외했습니다. 공개 합성 샘플과 입력 템플릿은 유지합니다. 캡처 도구를 실행하려면 본인이 제공할 권한이 있는 입력을 별도로 준비해야 합니다.

감사 planner는 이력 초기화 상태에서 과거 레코드 전부를 재검토 대상으로 표시합니다. 과거 성공 기록으로 현재 테스트를 생략할 수 없습니다. 자세한 절차는 [감사 안내](audit/incremental-review.md)를 참고하세요.
